# SQL_Mini_Project

## About the Project
This project is part of my SQL learning journey. I created and practised SQL queries using a sample HR database for a fictional company called project_hr.

The database includes four tables:
- Employees
- Departments
- Jobs
- Attendance

## Topics Covered
- SELECT statements
- WHERE and ORDER BY
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries
- Correlated Subqueries
- SELF JOIN
- CASE WHEN

## Tools Used
- MySQL
- MySQL Workbench
- GitHub
- ChatGPT (for learning support, understanding SQL concepts, and guidance)

## Project Objectives
- Practise SQL queries using real-world HR scenarios.
- Understand how to retrieve and analyse data from multiple tables.
- Improve problem-solving and SQL query-writing skills.
- Build a foundation for an entry-level Data Analyst role.

## AI Assistance
I used ChatGPT as a learning assistant throughout this project to understand SQL concepts, clarify doubts, review queries, and improve my problem-solving approach. I practised the queries and worked on understanding the logic behind them.

## Learning Outcome
Through this project, I gained practical experience with SQL fundamentals, database relationships, joins, aggregate functions, and subqueries.

This project represents my learning progress as I continue developing my data analysis skills.
